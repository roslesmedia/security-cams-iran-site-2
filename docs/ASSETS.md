# DIDBAN asset provenance

The camera story and catalog archetypes are original procedural Three.js geometry,
not manufacturer models or engineering drawings. They describe conceptual forms
and must not be presented as exact branded hardware. Catalog entries are explicitly
unbranded demonstration installation briefs; prices, stock and verified technical
specifications are not supplied.

Estedad is distributed from the official repository:
https://github.com/aminabedi68/Estedad

The local regular and semibold WOFF2 files were obtained from repository commit
`0dbe689787b8c2ea302373cb601d0f352f9f98e5`.
Its SIL Open Font License is retained in `public/assets/ESTEDAD-LICENSE.txt`.

The illustrative storefront image is generated artwork retained as an environment
asset. It is not a photograph of a customer location or evidence of an installation.
The baked-in ceiling camera was removed with the image-generation tool so the
installation scene contains only the articulated WebGL camera.
Day/night, entrance events and phone notifications are conceptual demonstrations;
no monitoring or notification service is connected.

Three.js uses the MIT license. GSAP uses the GreenSock standard license. Dependency
license texts are available in the installed packages. The reference image supplied
in the task governs composition; it is not embedded as a webpage.

## Realism refinement

`camera-studio-photo.png` is an original AI-generated, unbranded studio concept
created with the available OpenAI image-generation tool. It illustrates powder-coated
metal, optical glass and mounting detail; it is not a manufacturer photograph.
Higgsfield and ElevenLabs tools were unavailable in this session and were not used.

Camera geometry uses original deterministic powdercoat bump textures, convex lens
surfaces, recessed infrared elements, fasteners and cast mounting forms.
`StudioLighting.ts` supplies the shared Three.js RoomEnvironment lighting for the
scroll story, interactive viewer and rendered catalog stills. The environment is
procedural; no external HDRI license or runtime image host is required.

The 143 camera/poster/story stills are fresh renders encoded as WebP at quality 0.94.
They replace the previous PNG set (11.67 MB); the new set is approximately 1.88 MB.
These are the same conceptual geometries used by the interactive scenes.
